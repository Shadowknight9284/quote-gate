# Synthetic experiment matrix: source and reproduction

- `source-20261010T165552Z.json` — the matrix behind the paper's Table 1 and Figure 1
  (`python3 -m quote_gate.experiments`; agent-run, 2026-10-10T16:55Z).
- `reproduced-20261010T210644Z.json` — regenerated by a team member running `scripts/demo.sh` at
  revision `e9a71db` (**human-run**, 2026-10-10T21:06Z).

The team member compared the two with the command below (run against the local copies under
`artifacts/`) and reported that every substantive key matched. No transcript of that comparison
was saved. Against these public copies, from the repository root:

```
python3 - docs/evidence/synthetic-matrix/reproduced-20261010T210644Z.json docs/evidence/synthetic-matrix/source-20261010T165552Z.json <<'PY'
import json, sys
with open(sys.argv[1]) as f: new = json.load(f)
with open(sys.argv[2]) as f: old = json.load(f)
print("Run IDs:", new.pop("run_id"), old.pop("run_id"))
for key in sorted(set(new) | set(old)):
    print(key, "MATCH" if new.get(key) == old.get(key) else "DIFFERENT")
assert new == old, "Substantive configuration/results differ"
print("Configuration, per-seed economics, aggregates and paired results match.")
PY
```
Only `run_id` is excluded. `paper/fig_paired.dat` is byte-identical to the figure data written
alongside the source matrix.
